# وين أرخص؟

اختار الخدمة، والموقع بيختارلك المنصة الأرخص وبيرتّبلك كل الدول بعملتك، مع البطاقة اللي بتلزمك.

**الموقع شغّال على:** https://qutaibaob01.github.io/wain-arkhas/

- **ألعاب:** الأكثر مبيعاً على PlayStation وXbox وSteam (بتتحدّث القائمة لحالها كل يوم)، والنسخة نفسها بكل الدول.
- **اشتراكات:** PlayStation Plus (Essential وExtra وPremium، شهر و3 شهور وسنة)، Xbox Game Pass Ultimate وPC Game Pass، EA Play.
- **شحن الألعاب:** شدات ببجي موبايل، V-Bucks فورتنايت، روبوكس، جواهر فري فاير، نقاط كول أوف ديوتي موبايل، جواهر موبايل ليجندز وكلاش أوف كلانس وبراول ستارز، كريستالات جنشن، عملات تيك توك.
- **تطبيقات (عن طريق App Store):** سناب شات بلس، يوتيوب بريميوم، نتفليكس، ديزني بلس، ديسكورد نيترو، تيليجرام بريميوم، ChatGPT.
- **22 دولة** وكل عملات العالم بقائمة العملة.

موقع ثابت (HTML وCSS وJavaScript بدون مكتبات)، مستضاف مجاناً على GitHub Pages، والأسعار بتتحدّث تلقائياً كل يوم عن طريق GitHub Actions.

## من وين بتيجي الأسعار؟

| المصدر | شو بنجيب منه |
| --- | --- |
| PlayStation Store | الألعاب الأكثر مبيعاً آخر 30 يوم وسعرها بكل دولة، وأسعار PS Plus من صفحتها الرسمية |
| Microsoft Store | الألعاب الأكثر مبيعاً، Game Pass وEA Play، وV-Bucks وRobux |
| Steam | الألعاب الأكثر مبيعاً + قائمة ثابتة بـ `data/sources.json` |
| App Store | المشتريات داخل التطبيقات (شدات، جواهر، اشتراكات) من صفحة كل تطبيق بكل دولة |
| open.er-api.com | أسعار صرف كل العملات |

**جوجل بلاي:** جوجل ما بتنشر أسعار المشتريات داخل التطبيقات لكل دولة على الويب، فما في مصدر رسمي. ما بنحط أرقام تقديرية.

أي سعر ما انجاب آخر 10 أيام بينشال لحاله. ملخص كل تحديث (كم سعر من كل مصدر وأي مشكلة) بملف `data/status.json`.

## كيف تضيف خدمة

**تطبيق أو شحن من App Store:** خذ رقم التطبيق من رابطه (مثلاً `apps.apple.com/app/id1330123889`) وشوف أسماء المشتريات بصفحته، وأضف خدمة لـ `data/sources.json`:

```json
{
  "id": "pubg-uc", "type": "currency", "name": "PUBG MOBILE UC", "ar": "شدات ببجي موبايل", "kw": "pubg uc ببجي شدات",
  "offers": {
    "apple": {
      "source": "apple", "app": "1330123889", "default": "uc-60",
      "items": [{ "id": "uc", "match": "^([\\d,]+)\\s+Unknown Cash$", "label": "{1} UC" }]
    }
  }
}
```

`match` تعبير نمطي لاسم المنتج بالمتجر، و`{1}` بالـ `label` هو الرقم الملتقط.

**إضافات لعبة على Xbox** (زي V-Bucks): `"source": "xbox-addons"` مع رقم اللعبة بـ `parent`.
**اشتراك Xbox:** `"source": "xbox"` مع `bigId` و`match` لمدة الاشتراك.
**لعبة ستيم ثابتة:** أضف رقمها لقائمة `steam`.

`type` واحد من: `game` أو `sub` أو `currency` أو `app`.

**دولة جديدة:** أضفها لـ `data/regions.json` مع رموزها بكل متجر (`ps` و`xbox` و`steam` و`apple`) وعملة بلايستيشن وآبل فيها.

## تشغيل محلي

```bash
python3 -m http.server 8000      # افتح http://localhost:8000
node --test scripts/test/update.test.mjs
node scripts/update.mjs          # تحديث الأسعار (بيحتاج Node 20 أو أحدث)
```

## تنبيه

الأسعار للمعلومية وممكن تتغيّر بأي لحظة. بطاقات الشحن مقفولة على دولتها، وما بننصح بتغيير المنطقة بالـ VPN. الموقع مش تابع لسوني أو مايكروسوفت أو Valve أو آبل، وكل الأسماء التجارية لأصحابها.
