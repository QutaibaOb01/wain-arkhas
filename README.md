# وين أرخص؟

موقع بيقارن سعر نفس اللعبة أو الاشتراك بين مناطق العالم، وبيحوّل كل الأسعار لعملة الزائر، وبيقله أي بطاقة شحن بتلزمه.

- موقع ثابت (HTML وCSS وJavaScript) بدون مكتبات وبدون خطوة بناء.
- مستضاف مجاناً على GitHub Pages.
- الأسعار بتتحدّث تلقائياً كل يوم عن طريق GitHub Actions.

## تشغيل الموقع على GitHub Pages

1. من المستودع افتح **Settings → Pages**.
2. تحت **Build and deployment** اختار **Source: GitHub Actions**.
3. افتح تبويب **Actions**، اختار «تحديث الأسعار ونشر الموقع»، واضغط **Run workflow**.
4. بعد دقيقتين تقريباً الموقع بيصير على:
   `https://<اسم-حسابك>.github.io/<اسم-المستودع>/`

بعدها كل تعديل بترفعه على `main` بينشر لحاله، والأسعار بتتحدّث كل يوم الساعة 3:17 بتوقيت UTC.

## من وين بتيجي الأسعار؟

| المصدر | المنتجات | التحديث |
| --- | --- | --- |
| Steam | ألعاب PC | تلقائي كل يوم |
| متجر Xbox | Game Pass Ultimate | تلقائي كل يوم |
| open.er-api.com | أسعار الصرف | تلقائي كل يوم |
| مصادر منشورة | بلايستيشن بلس وألعاب بلايستيشن | يدوي، من `data/manual-prices.json` |

متجر بلايستيشن ما بيعرض أسعار الاشتراكات بدون تسجيل دخول، فأسعار بلايستيشن يدوية، وكل سعر معه رابط مصدره وتاريخ التحقق منه.

بعد كل تحديث تلقائي بتلاقي ملخص اللي صار بملف `data/status.json` (كم سعر انجاب من كل منطقة وأي مشكلة صارت).

## الملفات

| الملف | شو فيه |
| --- | --- |
| `index.html` | هيكل الصفحة |
| `assets/css/app.css` | التصميم |
| `assets/js/app.js` | منطق الموقع والصفحات |
| `assets/js/config.js` | الإعدادات: رابط المستودع والعملة والمنطقة الافتراضية |
| `data/catalog.json` | المنتجات والأقسام والمنصات |
| `data/regions.json` | المناطق اللي بنقارن بينها |
| `data/manual-prices.json` | الأسعار اليدوية مع مصادرها |
| `data/auto-prices.json` | الأسعار التلقائية (لا تعدّله بإيدك) |
| `data/rates.json` | أسعار الصرف (بيتحدّث لحاله) |
| `scripts/update-prices.mjs` | سكربت التحديث التلقائي |
| `.github/workflows/update-and-deploy.yml` | التحديث اليومي والنشر |

## كيف تضيف منتج

**لعبة على ستيم:** خذ رقم اللعبة من رابطها على ستيم (مثلاً `store.steampowered.com/app/1245620/` رقمها `1245620`) وأضفها لـ `data/catalog.json`:

```json
{ "id": "steam-1245620", "name": "Elden Ring", "variant": "PC · Steam", "category": "pc", "platform": "steam", "source": { "type": "steam", "appid": 1245620 }, "keywords": "elden ring الدن رينج" }
```

أسعارها بتنزل مع التحديث التلقائي الجاي.

**منتج بسعر يدوي:** أضفه لـ `data/catalog.json` مع `"source": { "type": "manual" }`، وبعدين أضف أسعاره لـ `data/manual-prices.json`:

```json
"gta-6-ps5": {
  "TR": { "amount": 3999, "currency": "TRY", "checked": "2026-11-08", "source": "رابط المصدر" }
}
```

`amount` بعملة المنطقة، و`currency` رمز العملة (TRY، INR، USD…). كل عملة بتستخدمها لازم تكون موجودة بقائمة `CURRENCIES` بالسكربت.

**منطقة جديدة:** أضفها لـ `data/regions.json` برمزها المكوّن من حرفين (`PL`، `UA`…).

## تشغيل محلي

```bash
python3 -m http.server 8000
# افتح http://localhost:8000
```

ولتجرّب التحديث التلقائي محلياً (بيحتاج Node 20):

```bash
node scripts/update-prices.mjs
```

## الخطوات الجاية

- متاجر بطاقات معتمدة بأسعارها وروابط أفلييت.
- أسعار تلقائية لبلايستيشن واشتراكات التطبيقات.
- تنبيه لما ينزل سعر منتج.

## تنبيه

الأسعار للمعلومية وممكن تتغير. الموقع مش تابع لسوني أو مايكروسوفت أو Valve، وكل الأسماء التجارية لأصحابها.
